# 무료 시작과 글로벌 확장

## 현재 구현

- 계정/피드/반응/사진 저장은 같은 Supabase 프로젝트를 웹과 Expo가 공유합니다.
- Hi: 본인 입력 생년월일로 18+ 제한, 사전 참여 동의, 친구/데이트 목적, 상호 성별·나이 조건, 도시/전 세계 범위. 정확한 좌표를 수집하지 않습니다. 연결된 상대에게 도시와 5년 단위 나이대가 공개됩니다.
- 최근 7일 이내 참여 조건을 갱신한 회원을 대상으로, 조건에 맞는 최근 후보 최대 200명 중 한 명을 무작위 선택합니다. 완전히 균등한 전 세계 무작위 추첨은 아닙니다.
- Hi는 24시간당 최대 5회, 성공한 요청 사이 최소 1분. 한 쌍은 재연결하지 않으며, 받은 요청이 10개 이상 대기 중인 회원은 추가 매칭하지 않습니다. 응답 없는 요청은 24시간 뒤 만료됩니다.
- 고정 `hi`만 요청함으로 전달되고 상대 수락 후 자유로운 텍스트 DM이 가능합니다. 메시지 최대 1,000자, 10분당 60개. 클라이언트 요청 ID로 전송 재시도를 중복 저장하지 않습니다.
- 차단/신고는 서버에서 처리합니다. 차단된 대화는 읽기/전송이 중단되며 운영 검토용 기록이 보관됩니다. 신고 접수 테이블은 있으나 자동 심사나 상시 운영 인력이 존재한다고 주장하지 않습니다.
- 한국어/영어 전환은 Hi 화면에 적용됩니다. 기존 피드·로그인·메일 템플릿의 전체 다국어화는 후속 작업입니다.

## 비용과 호스팅 결정

현재 Vercel 계정은 **Hobby**로 확인되었습니다. [Hobby 공식 정책](https://vercel.com/docs/plans/hobby)은 개인·비상업 용도이므로 회사 SNS의 무료 정식 운영 조건에 맞지 않습니다. 임의 유료 전환은 하지 않았습니다.

대안인 [Netlify Free는 상업 프로젝트를 허용](https://www.netlify.com/blog/introducing-netlify-free-plan/)합니다. [현재 요금](https://www.netlify.com/pricing/)은 월 300 크레딧을 배포·요청·대역폭·컴퓨팅이 함께 사용합니다. 무제한 무료가 아닙니다. [무료 한도 소진 시 사이트가 중지](https://docs.netlify.com/manage/accounts-and-billing/billing/billing-for-credit-based-plans/billing-faq-for-credit-based-plans/)되므로 사용량을 확인해야 합니다. 유료 플랜/자동 충전 설정은 하지 않습니다.

`netlify.toml`과 `netlify/functions/capture.ts`를 준비했습니다. Vite 정적 화면과 `/api/capture` API를 함께 이전할 수 있습니다. `server/capture.ts`는 호스팅 서비스에 의존하지 않는 공통 Node 처리기이며, Vercel 어댑터도 유지합니다. Netlify 실제 계정 연결/배포/도메인 전환은 아직 실행하지 않았습니다. 서버 비밀 키는 새 호스팅의 서버 환경에만 별도로 저장해야 합니다.

Supabase도 [Free 한도](https://supabase.com/pricing)가 있습니다. 사진 저장/다운로드가 주된 비용 요인이므로 2MB JPEG 제한, 비공개 버킷, 만료되는 서명 URL, 외부 업로드 차단을 유지합니다. 메일함 요금과 앱 스토어 개발자 계정 요금은 웹 호스팅과 별개입니다. 아직 Apple/Google 계정이 없어 공식 앱 촬영 게시는 잠겨 있습니다.

웹 무료 배포와 공식 네이티브 앱 배포는 별도 조건입니다. [Apple의 공개 배포](https://developer.apple.com/help/account/membership/programs-overview/)에는 Developer Program 가입이 필요합니다. Android는 Cloud 프로젝트만으로도 [Play Integrity API 초기 통합](https://developer.android.com/google/play/integrity/setup)을 시작할 수 있지만, 현재 서버가 요구하는 `PLAY_RECOGNIZED`는 Google Play에 등록된 앱·인증서와 일치해야 합니다. 일반 사이드로드를 인증된 nepeel 앱 배포로 간주하거나 검증을 끄지 않습니다. 유료 계정 가입은 별도 사용자 결정 사항입니다.

## 응답 속도와 확장 구조

| 처리 | 현재 방식 | 확장 시 변경 |
| --- | --- | --- |
| 웹 정적 자산 | 해시 파일명, CDN 배포 가능한 Vite 산출물, Hi 화면 지연 로딩 | 주요 시장별 실제 Core Web Vitals 측정, 폰트 자체 호스팅 |
| 피드 | 20건씩 조회, 사진 URL 일괄 생성, 이미지 지연 로딩 | 키셋 피드 페이지네이션, 검색 전용 인덱스, 이미지 썸네일 파이프라인 |
| Hi/DM | 인덱스, 제한된 응답 크기, 커서 페이지네이션, 서버 권한·동시성 잠금 | 지역별 후보 큐와 읽기 모델, 조회 계획/부하 측정 |
| 실시간 | Hi 화면이 활성일 때만 구독, 본인 대화 필터, 변경 이벤트 합치기 | 트래픽 증가 시 비공개 Broadcast 채널과 서버 이벤트 큐 |
| 사진 인증 | 공통 Node 서버의 기기 검증, 1회성 촬영 증명 | 검증 워커/대기열, 안전한 재처리와 정리 작업 |
| DB | Supabase 단일 리전 Postgres/RLS | 주요 사용자 지역 기준 배치, 백업/복구, 필요할 때 유료 리소스 승인 |

CDN이 글로벌이어도 인증·DB 쓰기 지연은 DB 리전과 사용자의 거리에 영향을 받습니다. 전 세계 저지연이나 고가용성을 측정 없이 보장하지 않습니다. 다중 리전 DB와 대규모 사진 트래픽을 영구 무료로 약속하지 않습니다.

## 다음 출시 게이트

1. Zoho SMTP 설정은 사용자가 저장했고 새로고침 후 유지됨을 확인했습니다. 실제 가입 인증메일 수신과 로그인 복귀를 사용자 계정으로 확인해야 합니다. 인증 우회는 추가하지 않습니다.
2. GitHub `nepeel-com/homepage`에 소스 업로드 완료. 브라우저의 기존 로그인으로 동기화하고 원격 fetch 후 파일 내용을 비교했습니다.
3. Netlify Free 로그인/계정 연결 후 환경 설정, 임시 URL 검증, `nepeel.com` 도메인 전환 순으로 진행합니다. 준비되지 않은 대상에 DNS부터 변경하지 않습니다. 게시물·계정 삭제의 사진 정리 재시도 함수 `cleanup-media`가 예약 함수로 배포되었는지도 확인합니다.
4. 두 실제 성인 참여자의 동의하에 요청→수락→DM→차단 흐름과 기기 간 갱신을 확인합니다. 테스트용 가짜 회원을 운영 환경에 심지 않습니다.
5. 본인확인/나이 보증은 아직 없습니다. 자기신고만으로 인증된 성인이라고 표시하지 않습니다. 정식 데이팅 운영 전 지역별 자격 정책, 개인정보·보관/삭제 절차, 신고 대응 인력을 정해야 합니다.

## 계정·사진 삭제와 운영 점검

- 웹·앱의 회원 탈퇴는 현재 비밀번호와 DELETE 입력을 요구합니다. 서버는 로그인한 계정과 재인증 계정의 ID가 같은지 확인합니다. 계정·프로필·게시물·댓글·저장·Hi 설정과 대화가 삭제되며, 상대방의 대화 기록도 함께 없어집니다. 신고 기록 또한 관련 계정/대화 삭제 시 cascade로 삭제되므로 영구 보존된다고 안내하지 않습니다.
- DB 삭제 트리거는 파일 경로만 비공개 삭제 대기열에 남깁니다. 사진 정리 실패가 탈퇴 성공을 실패로 뒤집지 않습니다. Netlify는 하루 한 번 최대 500개를 재시도합니다. `media_cleanup_jobs`의 오래된 작업이 늘면 함수 로그·Supabase Storage 상태와 무료 사용량을 확인합니다. Storage API로 파일을 삭제해야 하며 `storage.objects` 행만 직접 지우면 안 됩니다.
- 가입 확인/메일 도착, 두 실제 계정의 DM 수락·차단, 별도 동의된 테스트 계정의 탈퇴는 출시 전 별도 확인이 필요합니다. 현재 단위 테스트는 로컬 데이터와 모의 HTTP 응답을 사용합니다.
- 신고 검토자는 Supabase의 제한된 운영 계정으로 `reports` 및 `connection_reports`를 확인합니다. 공개 클라이언트에 service-role 키를 주거나 신고 테이블 SELECT 권한을 부여하지 않습니다. 삭제·차단 판단은 담당자가 해당 자료를 검토한 후 수행하며 자동 판정이 있는 것처럼 표시하지 않습니다.

## 차별화 기능 순서

지금은 **카메라로 남긴 일상 + 서로 동의한 작은 Hi**에 집중합니다. 다음 후보는 실제 촬영 게시물에서 시작하는 인사, 같은 날의 촬영 주제를 공유하는 모임, 동네별 사진 산책입니다. 아직 구현하지 않은 기능을 작동하는 것처럼 화면에 배치하지 않습니다.
